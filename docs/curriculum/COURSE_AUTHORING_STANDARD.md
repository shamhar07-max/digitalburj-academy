# Course authoring standard (operational)

1. Start from the blueprint (`content/academy/catalog.ts`), never from blank.
2. Problem-first cold open on every substantive lesson.
3. One new concept per lesson; link recalls to earlier lesson IDs.
4. Every claim checkable: commands runnable, code complete, numbers concrete.
5. Knowledge checks test reasoning (scenario/decision/debugging), not recall.
6. Failure scenario mandatory for technical lessons (symptom → cause → fix).
7. Security note wherever auth/data/money/upload/AI appears.
8. AI topics: limits, verification, cost, privacy, human approval — always.
9. Business topics: use universe companies (CargoFlow, Medix, EstateX, LearnHub, ShopSphere, FinCore) with budgets/deadlines/constraints.
10. End every course with: final project + assessment + evidence list + next courses.
11. Run `npm run curriculum:validate`; zero errors before done.
